### AI Renovation Planning & Execution Copilot for Iran

> **تگ‌لاین:** «قبل از شروع، پروژه‌ت رو بفهم.» — Understand your renovation before you spend a rial.

## مسئله (Problem)

بازار بازسازی ایران یک کوپایلوت ندارد که پروژه را **قبل از شروع** قابل فهم، قابل قیمت‌گذاری و قابل اجرا کند. حلقهٔ معیوب فعلی:

```
scope مبهم → قیمت غیرقابل مقایسه → تغییر وسط کار → اختلاف → اعتماد کم
```

کارفرما دقیق نمی‌داند چه می‌خواهد، مجری از صفر باید scope را بفهمد، متریال و کیفیت شفاف نیست، و WBS استانداردی وجود ندارد.

## راه‌حل (Solution)

با ورودی عکس/ویدیو/توضیح متنی/متراژ/سلیقه/بودجهٔ کارفرما، هوش مصنوعی:

1. **Scope Understanding** — می‌فهمد چه چیزی باید تخریب، اصلاح یا اضافه شود.
2. **WBS Generation** — ساختار شکست کار و ترتیب اجرا (تأسیسات → سازه → پوشش → دکور) را می‌سازد.
3. **Material & Spec Suggestion** — متریال متناسب با بودجه و سبک پیشنهاد می‌دهد.
4. **Cost & Time Estimation** — بر اساس دادهٔ بازار واقعی ایران، هزینه و زمان تخمین می‌زند.
5. **Multi-Scenario Output** — چند سناریوی اقتصادی / استاندارد / باکیفیت / مناسب اجاره ارائه می‌دهد.

## مدل کسب‌وکار (Business Model)

**B2B2C** — برای کارفرما: تصمیم شفاف قبل از خرج پول. برای مجری: brief دقیق‌تر و اختلاف کمتر.
درآمد: اشتراک، فروش lead باکیفیت، کمیسیون اجرا (فازهای بعدی).

مسیر رشد محصول: **Planning → Contractor Matching → Quote Normalization → Execution Tracking → Escrow/Financing**
