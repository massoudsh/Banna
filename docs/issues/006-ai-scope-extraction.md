## هدف
تشخیص وضعیت فعلی فضا و خواستهٔ کارفرما از روی عکس/ویدیو/متن، و تولید یک Scope Summary قابل فهم.

## کارها
- [ ] طراحی prompt/pipeline تحلیل تصویر برای تشخیص عناصر فضا (کابینت، کاشی، لوله‌کشی قابل مشاهده و ...)
- [ ] ترکیب تحلیل تصویری با توضیح متنی کارفرما
- [ ] خروجی ساختاریافتهٔ Scope Summary (JSON قابل مصرف برای مراحل بعد)
- [ ] تست دقت روی نمونه‌های واقعی

## معیار پذیرش
Scope Summary تولیدشده توسط کارفرمایان تست به‌عنوان «درست و قابل فهم» ارزیابی شود (وابسته به Issue #013).
