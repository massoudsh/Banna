## هدف
ساخت پایهٔ دادهٔ قیمت واقعی بازار ایران که موتور تخمین هزینه (Issue #009) به آن وابسته است.

## کارها
- [ ] فهرست‌بندی آیتم‌های پرتکرار WBS (کابینت، کاشی، کفپوش، رنگ، لوله‌کشی، برق‌کشی و ...)
- [ ] جمع‌آوری بازهٔ قیمت متریال برای هر آیتم (چند منبع/فروشنده)
- [ ] جمع‌آوری بازهٔ دستمزد اجرا برای هر آیتم
- [ ] ساخت ساختار دادهٔ قابل نگهداری (جدول/دیتابیس ساده) برای به‌روزرسانی دوره‌ای

## معیار پذیرش
دیتاست اولیه حداقل آیتم‌های اصلی آشپزخانه، حمام/سرویس و اتاق‌ها را پوشش دهد.
