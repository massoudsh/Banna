# بک‌لاگ Issueها (Issue Backlog)

این پوشه پیش‌نویس Issueهای پروژهٔ **بنّا** است، آمادهٔ ایجاد روی GitHub Issues پس از اتصال حساب GitHub (تنظیمات پروژه → اتصال GitHub).

هر فایل `NNN-slug.md` شامل front matter زیر است:

```yaml
title: ...
labels: [...]
milestone: ...
```

و بدنهٔ فایل، بدنهٔ Issue است.

## اجرای دسته‌ای پس از اتصال GitHub

اسکریپت `scripts/create_github_issues.sh` تمام فایل‌های این پوشه را می‌خواند و با `gh issue create` روی مخزن متصل، Issue واقعی می‌سازد (نیازمند `gh auth login` و اتصال remote — هر دو باید از داخل پنل/تنظیمات پروژه انجام شود).
