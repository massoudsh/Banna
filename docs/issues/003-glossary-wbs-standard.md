## هدف
داشتن یک WBS مرجع و واژگان یکسان که موتور تولید WBS (Issue #007) روی آن ساخته می‌شود؛ نسخهٔ اولیه در [Glossary ویکی](../wiki/Glossary.md) ثبت شده.

## کارها
- [ ] تعریف ترتیب استاندارد فازهای اجرا (تخریب → تأسیسات → سازه → پوشش → کابینت/درب → رنگ/دکور)
- [ ] تعریف زیرآیتم‌های هر فاز به تفکیک فضا (آشپزخانه، حمام، نشیمن، خواب)
- [ ] هم‌راستاسازی واژگان با اصطلاحات رایج بازار (نه صرفاً مهندسی)

## معیار پذیرش
سند WBS مرجع تأیید شده و به‌عنوان ورودی طراحی موتور WBS استفاده شود.
