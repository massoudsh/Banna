## هدف
قفل کردن دامنهٔ MVP طبق [MVP-Scope](../wiki/MVP-Scope.md) پیش از شروع ساخت.

## کارها
- [ ] تأیید نهایی نوع پروژه (آپارتمان مسکونی)
- [ ] تأیید نهایی شهر شروع (تهران)
- [ ] تأیید فضاهای پوشش‌دادنی (آشپزخانه/حمام/نشیمن/خواب)
- [ ] تعریف معیار عددی پذیرش خطای تخمین هزینه

## معیار پذیرش
سند دامنهٔ MVP نهایی و امضاشده باشد، بدون ابهام برای تیم توسعه.
