# Project Intake

این entity نمایانگر ورودی اولیهٔ کارفرما برای پروژهٔ بازسازی است.

## فیلدهای اصلی
- `projectName`: نام پروژه
- `description`: شرح کوتاه نیازها، وضعیت فعلی و اهداف
- `budget`: بودجه پیشنهادی
- `surfaceArea`: متراژ تقریبی
- `files`: عکس‌ها و ویدیوهای آپلودشده

## نقش در سیستم
ورودی پروژه اولین نقطهٔ شروع برای ساخت brief است. از این داده، سیستم می‌تواند:
- scope اولیه را تشخیص دهد
- سطح بودجه را دسته‌بندی کند
- WBS اولیه بسازد
- مسیر بعدی را برای کارفرما و مجری روشن کند
