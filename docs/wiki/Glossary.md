# واژه‌نامه (Glossary)

| اصطلاح | توضیح |
|---|---|
| **Scope** | دامنهٔ دقیق کارهای موردنیاز یک پروژهٔ بازسازی |
| **WBS (Work Breakdown Structure)** | ساختار شکست کار — لیست ترتیب‌دار فعالیت‌های اجرایی پروژه |
| **Brief** | خروجی استانداردشدهٔ Scope+WBS+Estimate که به مجری ارسال می‌شود |
| **Quote** | پیشنهاد قیمت مجری برای اجرای یک Brief |
| **Quote Normalization** | فرآیند یکسان‌سازی quoteهای مختلف مجریان برای مقایسهٔ apple-to-apple |
| **Change Order** | تغییر در scope حین اجرا و اثر آن روی هزینه/زمان |
| **Escrow** | پرداخت امانی/مرحله‌ای متصل به مایلستون‌های اجرا |
| **B2B2C** | مدل کسب‌وکاری که از طریق یک واسط کسب‌وکاری (اینجا: مجری) به مصرف‌کنندهٔ نهایی می‌رسد |
